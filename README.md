# CampusWheels Vehicle-Rental Desk

## How to Run

Make sure Python is installed.

Open the Assignment_02 folder in the terminal and run:

python main.py

## Files

- rental.py - Contains the Vehicle, Renter, ElectricCar, and Motorbike classes.
- main.py - Demonstrates the program and tests the required features.
